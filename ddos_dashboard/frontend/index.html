About This Dashboard

Arcs: Represent DDoS traffic flows from an origin to a target.

Magnitude: The percentage of global DDoS traffic volume for that specific vector.

Points: Location of traffic anomalies. Red indicates high-confidence attacks.

Note: Cloudflare Radar provides country/ASN level data. For pinpoint IP accuracy, integration with internal logs or a GeoIP provider is required.
